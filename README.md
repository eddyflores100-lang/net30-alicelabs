## How to update

1. Edit `index.html` directly on GitHub (pencil icon) → commit → the page rebuilds itself.
2. When the Google Form application is created, replace the `#apply` PDF button `href` with the Google Form URL (keep the PDF link as a secondary option).
3. To attach a custom domain (e.g. `net30.alicelabs.space`): repo Settings → Pages → Custom domain, then add the CNAME record at the DNS provider.
